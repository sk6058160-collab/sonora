# Sonora — free music PWA (static)
Legal sources only, no downloads: unified Search (iTunes 30s previews, Internet Archive free full tracks, radio), free radio (Radio Browser API, HTTPS streams), Spotify official embeds (paste a track/album/playlist link; full tracks when logged into Spotify, else previews), Internet Archive embeds. Favorites in localStorage, lock-screen controls via Media Session.
iPhone: open the site in Safari → Share → Add to Home Screen.
