# Sonora — free music PWA (static)
Legal sources only, no downloads: unified Search (Internet Archive free full tracks, radio), free radio (Radio Browser API, HTTPS streams), Spotify official embeds (paste a track/album/playlist link; full tracks when logged into Spotify, else previews), Internet Archive embeds. Favorites in localStorage, lock-screen controls via Media Session.
iPhone: open the site in Safari → Share → Add to Home Screen.

Spotify search worker: see worker/ (needs your Spotify keys, not deployed). Without it, paste Spotify links in the Spotify tab.
